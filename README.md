# 🚥 Yeşile Asla Dönmeyen Trafik Işığı

## Dünyanın En İnatçı, En Bilimsel, En Absürt Trafik Işığı Simülatörü

Bu repository, insanlığın en büyük sorunlarından birine çözüm üretir: **Trafik ışığının yeşile dönmesini beklemek.**

### 🎯 Ama Dikkat!
Bu ışık **asla** yeşile dönmez. Bu bir hata değil, özelliktir. Bilimsel olarak kanıtlanmıştır (kanıt: bu kod).

## 🚀 Nasıl Çalıştırılır?

```bash
python trafik_isigi.py
```

Ve izle. Kırmızı. Sarı. Yine kırmızı. Sonsuza dek.

### Özellikler
- ✅ Gerçekten çalışır
- ✅ Yeşile dönmez
- ✅ Rastgele bekleme süreleri
- ✅ Ctrl+C ile durdurulabilir (ama ışık hâlâ kırmızı kalır)
- ❌ Yeşil renk (kasıtlı olarak yok)
